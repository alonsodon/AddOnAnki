# AddOnAnki

An Anki add-on that automates multimedia flashcard creation from a video + subtitle repository, using Anki's spaced repetition system (SRS) for language learning.

## What it does

Given a repository of videos and their subtitles, the add-on indexes the content and generates flashcards automatically, letting you build a study deck from real media instead of creating cards by hand.

## Tech

- Python 3.9
- Anki 2.1.54 (Qt5)

## Performance

- Indexing the repository: ~8 seconds
- Query/lookup time: a few milliseconds

## Background

Originally built as a Bachelor's thesis project (Universidad de Murcia), awarded Matrícula de Honor.
